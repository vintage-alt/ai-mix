# AI 100: Fundamentals Test Jupyter Notebook

This course makes use of Jupyter Notebooks which run inside of a docker container for the labs, this repository is the main resource for the course, here you'll have access to the resources and examples that are shown in the videos.

Quick-Start:

`sudo docker compose up`

Once your docker container is up and running, you can interact with the Jupyter Notebook by navigating to:

http://127.0.0.1:8888/lab

From there double-click on the lab you'd like to open.
